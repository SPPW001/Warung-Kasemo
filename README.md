# Warung Kasemo Demo Website

Static demo website untuk Warung Kasemo - Nusantara Food & Coffee.

## Jalankan lokal

```bash
python -m http.server 8080
```

Lalu buka `http://localhost:8080`.

## Deploy

Bisa langsung di-push ke GitHub dan di-deploy ke Vercel/Netlify sebagai static site.
